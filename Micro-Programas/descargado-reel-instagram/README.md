# 📥 Descargador de Reels de Instagram

Este es un programa pequeño con interfaz gráfica (Tkinter) para descargar Reels de forma segura y libre de publicidad invasiva.

## 🛠️ Requisitos de Instalación

### Paso 1: Instalar las librerías de Python
Abre tu terminal dentro de esta carpeta y ejecuta el siguiente comando para instalar las dependencias de código:
```bash
pip install -r requirements.txt
```

### Paso 2: Instalar FFmpeg (¡Indispensable!)
Para que el programa pueda unir el audio y el video en alta definición, necesitas tener **FFmpeg** en tu computadora.

1. Descarga el archivo comprimido oficial desde este enlace seguro: [FFmpeg Essentials](https://gyan.dev).
2. Abre el `.zip`, entra a la carpeta `bin` y copia el archivo `ffmpeg.exe`.
3. **Pega `ffmpeg.exe` justo aquí adentro, en esta misma carpeta**, al lado del archivo `principal.py`.

## 🚀 Cómo ejecutar el programa
Una vez completados los pasos anteriores, solo ejecuta en tu consola:
```bash
python principal.py
```
